# Optimize snapshot — apps/mobile/app/(tabs)/{plan,history}.tsx

**Date:** 2026-05-26
**Scope:** Extract 12 nested-in-render components from `plan.tsx` and `history.tsx` to dedicated files under `components/plan/` and `components/history/`.

## Problem addressed

Audit P2 (perf): components declared inside render functions remount on every parent render and force `useMemo(createStyles)` to rebuild styles each cycle. Both tabs concentrated 12 such components in two screen files of 1103 and 645 lines, hurting readability and re-render cost.

## Files created (12)

### `apps/mobile/components/plan/`
- `CoachInsights.tsx` — banner with sparkles icon + accent label + body text
- `MetricChip.tsx` — icon + tabular value, optional `tint`
- `CalibrationBanner.tsx` — alert banner with flask icon (calibration mode)
- `CalibrationDoneNotice.tsx` — dismissible success notice (em-dash → comma to comply with PRODUCT.md ban)
- `WeeklyGoalRing.tsx` — SVG ring progress with percent label
- `EmptyPlan.tsx` — 4-phase state machine: idle / submitting / polling / error (with retry + cancel-after-90s)
- `SendToWatch.tsx` — Garmin push button with status feedback

### `apps/mobile/components/history/`
- `types.ts` — shared `Sport`, `Workout`, `SPORT_META`, `sportColor(theme, sp)`, `sportOf`, date/duration/pace formatters, `PT_MONTHS[_FULL]`
- `Stat.tsx` — labeled value + unit (used by WorkoutCard)
- `ViewToggle.tsx` — list/calendar segmented control (lifted `view` state via props)
- `WorkoutCard.tsx` — sport icon + tint + load badge + stats row
- `MonthSummary.tsx` — 4-week bar chart + 3 stat cards (tempo, km, sessões)
- `MonthCalendar.tsx` — month grid with sport dots + nav + legend (lifted `monthOffset` via props)

## Changes in screen files

### `app/(tabs)/plan.tsx` — 1103 → 688 lines (−415, −37%)
- Removed 7 inline component definitions and the styles they owned (`goalCard`, `chip`, `coachBanner`, `calibBanner`, `calibDone`, `emptyWrap`, `pollingSpinner`, `emptyErrorCircle`, `emptyIconCircle`, `sendSection`, `sendFeedback`, `sendOk`, `generateBtn`, etc.).
- Kept screen-only styles (`heroCard`, `timeline`, `dayCard`, `moveBanner`, `actionBtn`).
- Imports rewired to `../../components/plan/*`.

### `app/(tabs)/history.tsx` — 645 → 148 lines (−497, −77%)
- Removed 5 inline component definitions.
- Lifted `monthOffset` state via `MonthCalendar` props; lifted `view` via `ViewToggle` props.
- Imports rewired to `../../components/history/*`.

## Architectural notes

- Every extracted component follows the same shape: `import { ..., useTheme, type Theme }` → `const { theme } = useTheme()` → `const styles = useMemo(() => createStyles(theme), [theme])`. No hardcoded colors.
- `sportColor()` replaces the per-render `SPORT_COLOR` map that history.tsx rebuilt every render — now a pure function taking `theme`.
- `useApi()` lives inside `EmptyPlan` and `SendToWatch` (not props) because the hook needs the auth context, and these components are owned exclusively by the plan screen.
- All copy preserved verbatim except CalibrationDoneNotice em-dash → comma (PRODUCT.md ban on em-dashes).
